# 🔧 PR: Исправление collectDataFromRange и обновление UI

## 📋 Суть изменений

Исправлена критическая ошибка в функции `collectDataFromRange`, которая не обрабатывала корректно диапазоны ячеек. Обновлён UI для полной поддержки всех функций.

---

## ❌ Проблема

Функция **collectDataFromRange** не работала с диапазонами:

### Что НЕ работало:
- ❌ `C1:C100` - диапазон столбца с указанием строк
- ❌ `A1:D50` - многомерные диапазоны
- ❌ Некорректная фильтрация пустых значений
- ❌ Нет обработки ошибок
- ❌ Нет нормализации входных данных

### Что работало:
- ✅ `A1` - одиночные ячейки
- ✅ `C:C` - полные столбцы

---

## 🧪 Как проверить

### Тест 1: Диапазон столбца
1. Откройте Google Sheets с установленным Table AI
2. Выделите ячейку для результата
3. Меню → 🎯 AI Конструктор → 🎯 Настроить запрос
4. System Prompt: любой лист и ячейка с инструкцией

3. **Ожидаемый результат:** Поле автоматически заменится на `B1:B`

### Тест 3: Предпросмотр

2. Нажмите 🚀 Запустить
