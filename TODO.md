## 🧪 ПЛАН ТЕСТИРОВАНИЯ (Full System Verification)

Чтобы гарантировать 100% работоспособность, необходимо создать следующие тесты:

### 1. Автоматизированные тесты бэкенда (Vitest)
- [ ] **Auth Flow Integrity:** Тест на корректность генерации `redirect_uri` (должен быть всегда домен оболочки).
- [ ] **D1 Performance:** Тест на скорость выборки 100+ постов из базы.
- [ ] **JWT Security:** Тест на отказ в доступе при поддельном токене.

### 2. Интеграционные тесты (Proxy Check)
- [ ] Проверка передачи заголовков `X-Real-IP` (важно для безопасности VK).
- [ ] Тест на таймауты (Cloudflare имеет лимит 30с, нужно убедиться, что длинные AI-запросы не отваливаются).

### 3. E2E Тесты (Playwright/Cypress)
