## 🔄 ПРОЦЕСС РАБОТЫ

1. **Запрос клиента** → `callServerAction_(action, subaction, payload)`
2. **Отправка на сервер** → POST JSON {action, subaction, spreadsheetId, ...}
3. **Диспетчер сервера** → `doPost()` маршрутизирует в нужный API модуль
4. **Выполнение логики** → на сервере с проверкой лицензий
5. **Ответ клиенту** → JSON {ok, data/error, logs}
6. **Обновление UI** → на основе ответа сервера

## 🚀 ПРЕИМУЩЕСТВА

- **Maintainability**: Вся логика в одном месте (сервер)
- **Security**: API ключи только на сервере
- **Performance**: Клиент легковесный и быстрый
- **Updates**: OTA обновления без ручного распространения
- **Scalability**: Легко добавлять новые функции
- **Compatibility**: Все функции работают без изменений для пользователя
