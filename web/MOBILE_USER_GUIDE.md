# 📱 Table AI Mobile - Руководство пользователя

## 🎯 Обзор

Table AI Mobile — это мобильное приложение для удобного управления Google Sheets с помощью AI. Приложение автоматически находит подключенные скрипты Table AI и предоставляет доступ ко всем функциям прямо с вашего телефона.

## 🚀 Быстрый старт

### 1. Авторизация
1. Откройте приложение
2. Нажмите "Войти через Google"
3. Разрешите доступ к таблицам и скриптам

### 2. Выбор таблицы
- **Автоматический поиск**: Приложение покажет все ваши Google Sheets
- **По ссылке**: Вставьте URL таблицы в поле поиска

### 3. Автоматическое подключение скрипта
Приложение автоматически:
- 🔍 Ищет скрипт Table AI в выбранной таблице
- 📋 Показывает процесс поиска с индикатором
- ✅ Подключает все доступные функции

## 🔧 Решение проблем

### ❌ Скрипт не найден
1. Откройте таблицу на компьютере
2. Меню → Extensions → Apps Script
3. Вставьте код Table AI
4. Сохраните и вернитесь в мобильное приложение

### ❌ Ошибка доступа
1. Убедитесь что вы владелец таблицы
2. Проверьте права доступа к Apps Script
3. Попробуйте повторный вход в Google

### ❌ Функция не выполняется
1. Откройте "Диагностика" в настройках
2. Проверьте статус скрипта
3. Посмотрите логи последней ошибки
