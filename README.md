# 🔮 Table AI: От Google Sheets к полноценному SaaS

**Table AI** — это мощная платформа для автоматизации анализа контента с помощью Gemini AI. Проект проходит масштабную трансформацию: от расширения для Google Sheets к независимому облачному решению (SaaS) на стеке Cloudflare.

---

## 🚀 Быстрый старт (SaaS Платформа)

Вы можете запустить и протестировать новую платформу прямо сейчас. Мы реализовали **Mock Auth**, чтобы вы могли войти без настройки реальных API ключей.

### 1. Запуск Бэкенда (Cloudflare Workers)
```bash
cd saas/backend
npm install
npm run db:init     # Инициализация локальной базы D1
npm run dev         # Запуск API на http://34.51.195.14:8787
```

### 2. Запуск Фронтенда (React + Vite)
```bash
cd web
npm install
npm run dev         # Запуск UI на http://34.51.195.14:5173
```

### 🧪 Как протестировать «Полную картину»:
1. Перейдите по адресу: `http://34.51.195.14:5173`.
2. Нажмите **"🚀 Тестовый вход (Mock)"**.
3. Вы попадете в новый дашборд, где скоро появятся функции импорта и AI-анализа.

## 🏗️ Архитектура системы

Проект разделен на две части для плавного перехода:

1.  **SaaS (Новое поколение):**
    - **Стек:** React 19, Cloudflare Workers (Hono), D1 (SQL), JWT.
    - **Где находится:** папки `saas/` и `web/`.
    - **Документация:** [SaaS Architecture](docs/SaaS_ARCHITECTURE.md).

2.  **Legacy (Google Sheets):**
    - **Стек:** Google Apps Script.
    - **Где находится:** папка `deploy/`.
    - **Документация:** [Legacy Architecture](docs/ARCHITECTURE.md).
