# 📋 README.md - Table AI

**Google Sheets AI Automation System**  
**Версия:** 3.0.0  
**Статус:** Production Ready (Thick Server + Thin Client)  

---

## 🎯 Что это?

**Table AI** - это система автоматизации Google Sheets с использованием Gemini AI, которая позволяет:

- 🤖 **AI Конструктор** - создавать сложные AI-конфигурации через визуальный интерфейс
- 📦 **Просмотр Распаковки** - анализировать и экспортировать обработанные данные
- 📥 **Импорт VK постов** - загружать и обрабатывать посты из ВКонтакте
- 🔍 **OCR распознавание** - распознавать текст с изображений
- ⚡ **Batch обновления** - массово обновлять ячейки с AI
- 🔄 **OTA Обновления** - автоматические обновления клиента

- ✅ Лицензирование и rate limiting
- ✅ Проксирование к Gemini API
- ✅ Серверное логирование
- ✅ Управление OTA обновлениями

## 🚀 Развертывание

### 1. Deploy Server (один раз)
```bash
# 1. Скопировать все файлы из deploy/ на сервер
# 2. Deploy server.gs как Web App
# 3. Установить в Project Settings:
#    - GEMINI_API_KEY (если нужно)
#    - Настроить права доступа
```

**Server Files:**
- `server.gs` - главный диспетчер
- `collectConfigAPI.gs` - AI конструктор
- `ocrAPI.gs` - OCR обработка
- `vkAPI.gs` - VK импорт
- `unpackingAPI.gs` - просмотр данных
- `batchUpdateAPI.gs` - batch обновления
- `license.gs` - лицензирование

### 2. Копирование Клиента (для каждого пользователя)
```bash
# 1. Скопировать Main.gs, *.html в новую таблицу
# 2. Установить в Project Settings:
#    - SERVER_URL = твой Web App URL сервера
# 3. Готово! Клиент автоматически обновится при следующем onOpen()
```

**Client Files:**
- `Main.gs` - тонкий клиент с OTA
- `CollectConfigUi.html` - UI конструктора
- `UnpackingViewerUI.html` - UI просмотра данных
- `SettingsUI.html` - UI настроек
- `logging_system.html` - просмотр логов
- `appsscript.json` - версионирование

### 3. Обновление кода
```bash
# Меняешь сервер → пушишь в main
# Пользователи видят уведомление об обновлении при следующем открытии таблицы
# Копируют новый код из диалога обновления
```

## 🔄 OTA Обновления

### Автоматические обновления
1. При `onOpen()` клиент проверяет обновления
2. Сервер сравнивает версии и возвращает список файлов
3. Пользователь видит уведомление об обновлении
4. Файлы скачиваются и применяются через диалог
5. Клиент перезапускается с новой версией

### Ручные обновления
- DEV меню → "🔄 Проверить обновления"
- Принудительная проверка обновлений независимо от версии

## 🔧 Добавление новых функций

### Серверная часть
1. Создать новый API модуль (e.g., `newFeatureAPI.gs`)
2. Добавить обработчик в `server.gs` диспетчер
3. Реализовать бизнес-логику в модуле
4. Добавить subaction маршрутизацию

### Клиентская часть
1. Добавить функцию меню в `Main.gs`
2. Вызывать через `callServerAction_('newFeature', 'action', payload)`
3. Обработать ответ и обновить UI

### Пример добавления функции
```javascript
// Сервер: newFeatureAPI.gs
function newFeatureAction(spreadsheetId, payload) {
  // Бизнес-логика здесь
  return { success: true, data: result };
}

// Сервер: server.gs диспетчер
case 'newFeature':
  return handleNewFeature(subaction, data, spreadsheetId);

// Клиент: Main.gs
function newFeatureMenu() {
  const result = callServerAction_('newFeature', 'action', payload);
  SpreadsheetApp.getUi().alert(result.message);
}
```
