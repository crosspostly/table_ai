# 🚀 Collect Config - Быстрый старт

## Что это?

**Collect Config** (AI Конструктор) - это система для создания сложных AI-запросов в Google Sheets без ограничений на длину формулы.

---

## 🎯 Основная идея

Вместо того чтобы писать длинную формулу:
```
=GM("Проанализируй данные: " & A1 & ", " & A2 & ", " & A3 & "..." & A1000)
```

Вы используете визуальный интерфейс:
1. Выбираете ячейку для результата
2. Указываете откуда брать инструкцию (System Prompt)
3. Указываете откуда брать данные (User Data)
4. Нажимаете "Запустить"

---

## 📝 Как использовать?

### Шаг 1: Подготовьте данные

**Лист "Инструкция" (ячейка A1):**
```
Проанализируй следующие отзывы и выдели основные проблемы.
Перечисли топ-5 проблем с количеством упоминаний.
```

**Лист "Отзывы" (столбец C):**
```
C1: Отличный товар, но доставка долгая
C2: Качество супер, но упаковка плохая
C3: Цена высокая, доставка медленная
...
C100: Товар хороший, доставка долго шла
```

### Шаг 2: Откройте AI Конструктор

1. Выделите ячейку где нужен результат (например, лист "Анализ", ячейка B5)
2. Меню → **🤖 Table AI** → **🎯 AI Конструктор** → **🎯 Настроить запрос**

### Шаг 3: Настройте конфигурацию

**System Prompt:**
- Лист: `Инструкция`
- Ячейка: `A1`

**User Data:**
- Нажмите "+ Добавить данные"
- Лист: `Отзывы`
- Ячейка: `C1:C100` (или просто `C:C` для всего столбца)

### Шаг 4: Запустите

Нажмите **🚀 Запустить** - результат появится в выбранной ячейке!

## 📊 Типы диапазонов

### ✅ Поддерживаются все форматы:

| Формат | Пример | Описание |
|--------|--------|----------|
| Одиночная ячейка | `A1`, `B5` | Одно значение |
| Диапазон столбца | `C1:C100` | Диапазон с конкретными строками |
| Полный столбец | `C:C`, `A:B` | Весь столбец от первой до последней строки с данными |
| Многомерный диапазон | `A1:D50` | Прямоугольная область |

### 💡 Какой формат выбрать?

- **Одиночная ячейка** (`A1`) - для параметров, настроек
- **Диапазон столбца** (`C1:C100`) - когда точно знаете количество строк
- **Полный столбец** (`C:C`) - для динамических данных (количество строк меняется)
- **Многомерный диапазон** (`A1:D50`) - для таблиц с несколькими столбцами

## 🎨 Примеры использования

### Пример 1: Анализ отзывов

**Задача:** Проанализировать 500 отзывов клиентов

**Настройка:**
- System Prompt: `Инструкция!A1` - "Проанализируй отзывы и найди топ-5 проблем"
- User Data: `Отзывы!C:C` - весь столбец с отзывами
- Результат: `Анализ!B5`

**Результат:** AI проанализирует все отзывы и выдаст топ-5 проблем

---

### Пример 2: Генерация описаний товаров

**Задача:** Сгенерировать описание товара на основе характеристик

**Настройка:**
- System Prompt: `Промпты!B1` - "Напиши продающее описание товара на основе характеристик"
- User Data:
  - `Товары!A5` - название товара
  - `Товары!B5:F5` - характеристики (цена, размер, материал и т.д.)
- Результат: `Товары!G5`

**Результат:** Готовое описание товара для каталога

---

### Пример 3: Сравнение данных из разных источников

**Задача:** Сравнить данные из двух разных листов

**Настройка:**
- System Prompt: `Инструкция!C1` - "Сравни данные из двух источников и найди расхождения"
- User Data:
  - `Источник1!A:A` - данные из первого источника
  - `Источник2!A:A` - данные из второго источника
- Результат: `Сравнение!A1`

**Результат:** Список расхождений с пояснениями

## ⚡ Преимущества

### 1. Нет лимита на длину промпта
Google Sheets ограничивает формулы 50,000 символами. CollectConfig собирает данные на сервере - без лимитов!

### 2. Динамические данные
Можете указать `C:C` и AI всегда будет брать актуальные данные, даже если вы добавите новые строки.

### 3. Переиспользование
Настройка сохраняется! Можете обновить результат одной кнопкой: **🔄 Обновить ячейку**

### 4. Структурированный запрос
Все данные отправляются в AI в JSON-формате - нейросеть лучше понимает структуру.

**После исправления:**

- ✅ `A1:D50` - работает идеально
- ✅ Пустые значения корректно фильтруются
- ✅ Регистр не важен: `c1:c100` = `C1:C100`
- ✅ Пробелы игнорируются: `  A1:A10  ` работает

## 🐛 Решение проблем

### Проблема: "Не сохраняется конфигурация"

**Решение:**
1. Проверьте что вы выбрали и лист, и ячейку
2. Откройте консоль браузера (F12) и проверьте ошибки
3. Попробуйте закрыть и открыть интерфейс снова

### Проблема: "Не выполняется запрос"

**Решение:**
1. Проверьте что API ключ настроен: Меню → **⚙️ Настройки**
2. Проверьте что листы и ячейки существуют
3. Проверьте логи: Меню → **🧰 DEV** → **🔍 Показать логи AI Конструктора**

### Проблема: "Диапазон не работает"

**Убедитесь что:**
- Диапазон написан правильно: `C1:C100` (не `C1-C100`)
- Лист существует и название точное (с учётом пробелов!)
- В диапазоне есть хоть какие-то данные

## 💡 Советы

1. **Для больших объёмов данных**: Используйте конкретные диапазоны (`A1:A1000`) вместо полных столбцов (`A:A`) - быстрее работает

2. **Для динамических данных**: Используйте полные столбцы (`C:C`) - автоматически подхватывает новые строки

3. **Тестируйте на малых данных**: Сначала протестируйте на `C1:C10`, потом расширяйте на весь столбец

4. **Сохраняйте конфигурацию**: Нажмите **💾 Сохранить** перед запуском - потом легко обновить

5. **Используйте предпросмотр**: Система показывает первые 100 символов из ячейки - проверьте что выбрали правильные данные
