│ DEPLOYMENT STEPS                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

STEP 1: CLIENT Setup
  ☐ Open Google Sheet in production
  ☐ Go to Extensions → Apps Script
  ☐ Create/edit script
  ☐ Upload 9 files from deploy/ folder
  ☐ Update appsscript.json
  ☐ Deploy script

STEP 2: Environment Setup
  ☐ Set GEMINI_API_KEY (Extensions → Script Properties)
  ☐ Set VK_PARSER_URL
  ☐ Set SERVER_URL (or SERVER_DEPLOYMENT_ID)
  ☐ Set DEV_MODE = false (production)

STEP 3: SERVER Setup
  ☐ Create separate Google Apps Script project
  ☐ Upload Server_v3_IMPROVED.gs
  ☐ Deploy as Web App
  ☐ Get deployment URL
  ☐ Add URL to CLIENT as SERVER_URL

STEP 4: Testing
  ☐ Refresh sheet (F5)
  ☐ Menu should appear: 🤖 Table AI
  ☐ Test each menu item
  ☐ Check logs: 🧰 [DEV] → 📝 Show Logs
  ☐ Verify no console errors

STEP 5: Production Release
  ☐ Merge PR to main branch
  ☐ Tag release: git tag v3.0.1-released
  ☐ Monitor logs for 24 hours
  ☐ Notify users about new features
