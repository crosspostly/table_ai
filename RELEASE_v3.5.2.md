# 🚀 Release v3.5.2 - OTA Backward Compatibility Fix

## 📋 Краткое описание

Исправлена критическая ошибка обратной совместимости OTA системы. Старые клиенты (v3.4.x) теперь могут автоматически обновиться до новой версии без ручного вмешательства.

---

## ❌ Проблема

**До v3.5.2:**
```
Ошибка при нажатии "🔄 Автообновление":
ReferenceError: checkForUpdates_ is not defined
```

**Причина:**
- В v3.4.x функция называлась `checkForUpdates_()`
- В v3.5.0 переименована в `checkForUpdatesBackground_()`
- Старые триггеры/вызовы продолжали использовать старое имя
- Функция отсутствовала → ошибка → обновление невозможно

---

## ✅ Решение

**Добавлена алиас-функция для обратной совместимости:**

```javascript
// deploy/Main.gs, строка 2034
/**
 * DEPRECATED ALIAS: Для обратной совместимости со старыми версиями
 */
function checkForUpdates_() {
  addLog('⚠️ DEPRECATED: checkForUpdates_() - используется алиас', 'WARN');
  addLog('ℹ️ Перенаправление на checkForUpdatesBackground_()...', 'INFO');
  return checkForUpdatesBackground_();
}
```

**Результат:**
- ✅ Старые триггеры работают
- ✅ Старые вызовы перенаправляются автоматически
- ✅ Клиенты обновляются без ошибок
- ✅ Логирование отслеживает использование deprecated функции

## 🔧 Как обновиться

### Для администраторов (серверная часть)

**1. Обновить GitHub репозиторий:**
```bash
git pull origin main
# Убедитесь что SERVER_VERSION = '3.5.2' в deploy/server.gs
```

**2. Deploy сервера:**
```bash
cd path/to/server
clasp push --force
```

**3. Готово!** Все клиенты получат обновление автоматически.

### Для пользователей (клиентская часть)

**Вариант 1: Автоматически (рекомендуется)**
1. Откройте таблицу
2. Меню: **🤖 Table AI → 🔄 Автообновление**
3. Подождите 1-2 минуты
4. ✅ Получите email об успешном обновлении

**Вариант 2: Вручную (если OTA не работает)**
1. Extensions → Apps Script
2. Скопируйте все файлы из GitHub `deploy/` папки
3. Сохраните (Ctrl+S)
4. Обновите страницу таблицы (F5)
5. ✅ Готово!

## 📈 Метрики успеха

**Как измерить успешность релиза:**

1. **Логи сервера** - искать строку:
   ```
   ⚠️ DEPRECATED: checkForUpdates_() вызвана
   ```
   - Если много → ещё есть старые клиенты
   - Если нет → все обновились

2. **Количество ошибок** в GitHub Issues:
   - До релиза: "checkForUpdates_ is not defined"
   - После релиза: должно быть 0

3. **Email уведомления** пользователям:
   - "✅ Table AI обновлён до версии 3.5.2"
   - Если получили → обновление прошло успешно
