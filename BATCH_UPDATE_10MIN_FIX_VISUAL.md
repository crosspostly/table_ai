## 🐛 ЧТО БЫЛО СЛОМАНО

### ❌ СТАРЫЙ КОД (БАГ):

```javascript
if (lastRunStr && lastSuccess === true) {
  try {
    const lastRun = new Date(lastRunStr);
    const diffMs = now - lastRun;

    if (diffMs < skipThresholdMs) {
      const minutesAgo = Math.floor(diffMs / 60000);
      addLog(`⏭️ Пропуск ${sheet}!${cell} (✅ успешно ${minutesAgo} мин назад)`, 'INFO');
      continue; // ⏭️ ПРОПУСКАЕМ только успешные < 10 минут
    }
    // ❌ ПРОБЛЕМА: если diffMs >= skipThresholdMs, НЕТ else-блока!
    // Код падает в cellsToUpdate.push() ПОСЛЕ if/else блока
  } catch (e) {
    // Если ошибка парсинга даты - обновляем
  }
} else if (lastRunStr && lastSuccess === false) {
  // ...логирование...
}

// ❌ ПРОБЛЕМА: cellsToUpdate.push() ВСЕГДА выполняется для НЕ-пропущенных!
cellsToUpdate.push({
  sheet: sheet,
  cell: cell,
  configRow: startRow + i,
});
```

**ПРОБЛЕМА:** 
- `continue` работал ТОЛЬКО для `diffMs < skipThresholdMs`
- Для `diffMs >= skipThresholdMs` код НЕ делал `continue`, поэтому ячейка **ДОЛЖНА была** добавляться
- НО! Код **работал правильно** с точки зрения логики!

**РЕАЛЬНАЯ ПРОБЛЕМА была в неявности:** 
Код работал, но его было **сложно отладить** из-за отсутствия:
1. Явного флага `shouldSkip`
2. Подробного DEBUG логирования
3. Чёткого разделения случаев

### ✅ НОВЫЙ КОД (ИСПРАВЛЕН):

```javascript
let shouldSkip = false; // ✅ Явный флаг

if (lastRunStr && lastSuccess === true) {
  // ...
  if (diffMs < skipThresholdMs) {
    shouldSkip = true; // ✅ Явно устанавливаем
    addLog(`⏭️ ПРОПУСК: ...`, 'INFO');
  } else {
    // ✅ Явно логируем ОБНОВЛЕНИЕ
    addLog(`🔄 ДОБАВЛЕН: ...`, 'INFO');
  }
} else if (lastRunStr && lastSuccess === false) {
  // ✅ Явно логируем
  addLog(`🔄 ДОБАВЛЕН: ...`, 'INFO');
} else if (!lastRunStr) {
  // ✅ Явно логируем
  addLog(`🆕 ДОБАВЛЕН: ...`, 'INFO');
}

// ✅ Явная проверка флага
if (!shouldSkip) {
  cellsToUpdate.push({...});
}
```

**ПРЕИМУЩЕСТВА:**
- ✅ Явный контроль через `shouldSkip`
- ✅ Подробное DEBUG логирование на каждом шаге
- ✅ Чёткие INFO логи с причиной решения
- ✅ Легко отлаживать и тестировать

## 🎓 ГРАНИЧНЫЕ СЛУЧАИ

### Ровно 10 минут:

```
diffMs = 600000 ms (ровно 10 минут)
skipThresholdMs = 600000 ms

diffMs < skipThresholdMs?
600000 < 600000 = FALSE

➡️ shouldSkip = false ✅ ОБНОВЛЯЕТСЯ
```

**Важно:** Используем `<` (меньше), а не `<=` (меньше или равно), поэтому:
- **< 10 минут** → ПРОПУСК
- **>= 10 минут** → ОБНОВЛЕНИЕ (включая ровно 10 минут)
