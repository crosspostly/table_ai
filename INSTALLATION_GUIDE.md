# 📦 INSTALLATION GUIDE - Template System v2.0

**Дата:** 18 октября 2025  
**Версия:** 2.0.0

---

## 🎯 ЧТО ЭТО?

Template System v2.0 - это система шаблонов для "AI Конструктора" в Table AI.

Позволяет:
- ✅ Сохранять сложные настройки AI запросов
- ✅ Быстро загружать шаблоны для повторного использования
- ✅ Делиться настройками между проектами
- ✅ Мигрировать данные из старого ConfigData

---

## 📦 ФАЙЛЫ ДЛЯ УСТАНОВКИ

Из папки `deploy/` нужно скопировать **4 файла** в ваш CLIENT Apps Script проект:

```
deploy/
├── Main.gs                    ← 1. Главный файл (60 KB)
├── TemplateService.gs         ← 2. Управление шаблонами (15 KB)
├── CollectConfigUI.gs         ← 3. Server endpoints (15 KB)
└── CollectConfigUI_v2.html    ← 4. UI интерфейс (17 KB)
```

**ВАЖНО:** Файл `server.gs` НЕ НУЖЕН! Он для централизованного сервера (уже развёрнут).

**ВАЖНО:** Файл `MIGRATION.gs` ОПЦИОНАЛЕН (только если есть старые данные ConfigData).

---

## 🚀 УСТАНОВКА (ПОШАГОВО)

### Шаг 1: Открыть Apps Script

1. Откройте ваш Google Sheets документ
2. Меню: **Extensions** → **Apps Script**
3. Откроется редактор Apps Script

---

### Шаг 2: Скопировать Main.gs

**ВАЖНО:** Если у вас уже есть Main.gs с вашим кодом - сделайте backup!

1. В редакторе Apps Script найдите файл `Code.gs` или `Main.gs`
2. **Скопируйте ВЕСЬ контент** из `deploy/Main.gs`
3. **Замените** содержимое файла
4. Нажмите **Ctrl+S** (сохранить)

**Проверка:** В меню должна появиться функция `onOpen`

---

### Шаг 3: Добавить TemplateService.gs

1. В редакторе Apps Script нажмите **+** (Add a file) → **Script**
2. Назовите файл: `TemplateService`
3. **Скопируйте ВЕСЬ контент** из `deploy/TemplateService.gs`
4. Вставьте в новый файл
5. Нажмите **Ctrl+S**

**Проверка:** Файл должен содержать функции: `getAllTemplates`, `saveTemplate`, `deleteTemplate`

---

### Шаг 4: Добавить CollectConfigUI.gs

1. Нажмите **+** → **Script**
2. Назовите файл: `CollectConfigUI`
3. **Скопируйте ВЕСЬ контент** из `deploy/CollectConfigUI.gs`
4. Вставьте
5. Нажмите **Ctrl+S**

**Проверка:** Файл должен содержать функции: `serverGetAllTemplates`, `serverSaveTemplate`, и т.д.

---

### Шаг 5: Добавить CollectConfigUI.html

**ВАЖНО:** HTML файл должен называться ТОЧНО `CollectConfigUI` (без `_v2`!)

1. Нажмите **+** → **HTML**
2. Назовите файл: `CollectConfigUI` (БЕЗ _v2!)
3. **Скопируйте ВЕСЬ контент** из `deploy/CollectConfigUI_v2.html`
4. Вставьте
5. Нажмите **Ctrl+S**

**ПРОВЕРКА КРИТИЧНА:** Имя должно быть `CollectConfigUI`, НЕ `CollectConfigUI_v2`!

---

### Шаг 6: (ОПЦИОНАЛЬНО) Добавить MIGRATION.gs

**Только если у вас есть старые данные ConfigData для миграции!**

1. Нажмите **+** → **Script**
2. Назовите файл: `MIGRATION`
3. Скопируйте контент из `deploy/MIGRATION.gs`
4. Вставьте и сохраните

---

### Шаг 7: Проверка установки

1. **Закройте** редактор Apps Script
2. **Обновите** Google Sheets (Ctrl+F5)
3. В меню должен появиться: **🤖 Table AI**
4. Раскройте меню → должен быть пункт: **🎯 AI Конструктор (Template System v2.0)**

---

## 🚨 TROUBLESHOOTING

### Проблема 1: Меню не появляется

**Симптомы:** После установки нет меню "🎯 AI Конструктор"

**Причины:**
1. Main.gs не был обновлён
2. Функция `onOpen()` не сохранена

**Решение:**
1. Откройте Apps Script Editor
2. Проверьте что Main.gs содержит строку: `.addSubMenu(ui.createMenu('🎯 AI Конструктор (Template System v2.0)')`
3. Ctrl+S (сохранить)
4. Ctrl+F5 в Sheets

---

### Проблема 2: "Ошибка открытия интерфейса"

**Симптомы:** При нажатии "Настроить запрос" ошибка: "Error opening UI"

**Причина:** HTML файл называется неправильно!

**Решение:**
1. Apps Script Editor
2. Найдите HTML файл
3. Переименуйте в: `CollectConfigUI` (БЕЗ _v2)
4. Ctrl+S
5. Попробуйте снова

---

### Проблема 3: "Function not found: getAllTemplates"

**Симптомы:** Ошибка при открытии UI или сохранении шаблона

**Причина:** TemplateService.gs не установлен

**Решение:**
1. Apps Script Editor
2. Проверьте наличие файла `TemplateService.gs`
3. Если нет - создайте (Шаг 3)
4. Ctrl+S

---

### Проблема 4: "Function not found: serverGetAllTemplates"

**Симптомы:** UI открывается, но кнопки не работают

**Причина:** CollectConfigUI.gs не установлен

**Решение:**
1. Apps Script Editor
2. Проверьте наличие файла `CollectConfigUI.gs`
3. Если нет - создайте (Шаг 4)
4. Ctrl+S

## 📊 ЗАВИСИМОСТИ

Template System требует следующие файлы:

| Файл | Зависит от | Примечание |
|------|-----------|-----------|
| **Main.gs** | — | Главный файл, создаёт меню |
| **TemplateService.gs** | PropertiesService, LockService | Хранение шаблонов |
| **CollectConfigUI.gs** | TemplateService.gs | Server endpoints для HTML |
| **CollectConfigUI.html** | CollectConfigUI.gs | UI, вызывает через google.script.run |

**Все зависимости внутренние!** Не требуется внешних библиотек!

## 🔒 БЕЗОПАСНОСТЬ

### Где хранятся данные?

**Шаблоны:** `PropertiesService.getUserProperties()`
- ✅ Локально у каждого пользователя
- ✅ Не видны другим пользователям
- ✅ Привязаны к вашему Google аккаунту

**Конкуррентность:** `LockService.getScriptLock()`
- ✅ Защита от race conditions
- ✅ Безопасные concurrent writes
- ✅ Автоматическое освобождение locks

## 📝 ИСПОЛЬЗОВАНИЕ

### Создать шаблон:

1. **🎯 AI Конструктор** → **🎯 Настроить запрос**
2. Заполните:
   - System Prompt (лист + ячейка)
   - User Data (добавьте несколько источников)
3. **💾 Сохранить как шаблон**
4. Введите имя: "Анализ отзывов"
5. Готово!

---

### Загрузить шаблон:

1. **🎯 Настроить запрос**
2. Dropdown **📂 Шаблоны** → выберите "Анализ отзывов"
3. Нажмите **📂 Загрузить**
4. Все поля заполнятся автоматически!

---

### Удалить шаблон:

1. **🎯 Настроить запрос**
2. Dropdown **📂 Шаблоны** → выберите шаблон
3. Нажмите **🗑️ Удалить шаблон**
4. Подтвердите
