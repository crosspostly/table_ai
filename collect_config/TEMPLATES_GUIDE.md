## 🎯 Что такое шаблоны?

**Шаблоны** — это сохранённые конфигурации для AI Конструктора, которые можно:
- ✅ Создавать и сохранять
- ✅ Загружать и переиспользовать
- ✅ Редактировать и удалять
- ✅ Применять к разным ячейкам
- ✅ Экспортировать и импортировать

---

## 🆕 Что нового в версии 2.0?

### До (v1.0):
```
❌ Конфигурация привязана к ячейке
❌ Хранится в скрытом листе ConfigData
❌ Нет переиспользования
❌ Нет управления версиями
```

### После (v2.0):
```
✅ Шаблоны независимы от ячеек
✅ Хранятся в PropertiesService (быстрее)
✅ Легко переиспользовать
✅ Multi-user поддержка
✅ Защита от race conditions
```

## 🚀 Быстрый старт

### 1. Создание шаблона

```
1. Выделите ячейку → Меню → 🎯 AI Конструктор
2. Настройте System Prompt и User Data
3. Введите имя шаблона: "Мой первый шаблон"
4. Нажмите 💾 Сохранить
```

### 2. Загрузка шаблона

```
1. Откройте AI Конструктор
2. Выберите шаблон из выпадающего списка
3. Нажмите 📂 Загрузить
4. Измените если нужно
5. Нажмите 🚀 Запустить
```

### 3. Обновление шаблона

```
1. Загрузите шаблон
2. Измените конфигурацию
3. Оставьте то же имя в поле "Имя шаблона"
4. Нажмите 💾 Сохранить (перезапишет)
```

### 4. Удаление шаблона

```
1. Выберите шаблон из списка
2. Нажмите ❌ (красная кнопка)
3. Подтвердите удаление
```

### Миграция из старой версии

Если у вас есть данные в листе `ConfigData` (старая версия):

```
1. Меню → Скрипт → showMigrationPreview()
   ↳ Покажет сколько записей будет мигрировано

2. Меню → Скрипт → interactiveMigration()
   ↳ Выполнит миграцию с подтверждением

3. Проверьте результат в AI Конструкторе
   ↳ Шаблоны с пометкой "(migrated)"
```

**Откат миграции:**
```javascript
rollbackMigration();  // Удалит все шаблоны с "(migrated)"
```

## 📊 Лимиты и ограничения

### PropertiesService лимиты:

| Параметр | Лимит | Комментарий |
|----------|-------|-------------|
| **Размер одного шаблона** | 8 KB | Проверяется автоматически |
| **Шаблонов на пользователя** | 100 | Настраивается в `MAX_TEMPLATES_PER_USER` |
| **Общий размер storage** | ~500 KB | Google Apps Script лимит |

### Обход лимитов:

**Если шаблон > 8KB:**
```
❌ Проблема: "Конфигурация слишком большая"
✅ Решение:
   1. Уменьшите количество userData источников
   2. Используйте диапазоны вместо отдельных ячеек
   3. Разбейте на несколько шаблонов
```

**Если достигнут лимит 100 шаблонов:**
```
❌ Проблема: "Достигнут лимит шаблонов"
✅ Решение:
   1. Удалите неиспользуемые шаблоны
   2. Экспортируйте старые в JSON
   3. Используйте более общие шаблоны
```

## 🛡️ Безопасность и надёжность

### Multi-user поддержка

✅ Каждый пользователь видит только свои шаблоны  
✅ Идентификация по `Session.getActiveUser().getEmail()`  
✅ Нет конфликтов между пользователями

### Защита от race conditions

```javascript
// LockService автоматически защищает:
const lock = LockService.getScriptLock();
lock.waitLock(30000);  // Ждём до 30 секунд

// Ваша операция

lock.releaseLock();
```

### Валидация данных

Система проверяет:
- ✅ Структуру конфигурации
- ✅ Наличие обязательных полей
- ✅ Размер данных
- ✅ Корректность JSON

## 🐛 Troubleshooting

### Проблема: "Не удалось получить блокировку"

**Причина:** Другой процесс использует storage

**Решение:**
```
1. Подождите 30 секунд
2. Попробуйте снова
3. Если повторяется — перезапустите скрипт
```

---

### Проблема: "Шаблон не найден"

**Причина:** Шаблон был удалён или недоступен

**Решение:**
```
1. Обновите список шаблонов (переоткройте диалог)
2. Проверьте что вы авторизованы
3. Проверьте лог ошибок
```

---

### Проблема: "Template storage corrupted"

**Причина:** Повреждены данные в PropertiesService

**Решение:**
```
1. Экспортируйте шаблоны (если возможно)
2. Очистите storage:
   PropertiesService.getScriptProperties().deleteProperty('COLLECT_CONFIG_TEMPLATES')
3. Импортируйте из резервной копии
```

## 📈 Best Practices

### 1. Именование шаблонов

```
✅ Хорошо:
   - "Анализ отзывов - тональность"
   - "Описание товара - краткое"
   - "Email рассылка - приветствие"

❌ Плохо:
   - "template1"
   - "test"
   - "новый"
```

### 2. Структура промптов

```
✅ System Prompt в отдельной ячейке
   → Легко обновить без изменения шаблона

✅ User Data в диапазонах
   → A1:A100 вместо A1, A2, A3...

✅ Используйте листы-справочники
   → "Prompts", "Templates", "Instructions"
```

### 3. Версионирование

```
✅ Создавайте версии шаблонов:
   - "Анализ отзывов v1"
   - "Анализ отзывов v2 (улучшенный)"
   - "Анализ отзывов v3 (с эмодзи)"

✅ Экспортируйте перед большими изменениями
```
