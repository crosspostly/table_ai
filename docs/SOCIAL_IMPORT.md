# 📱 Social Import Documentation

## 📌 Обзор

Модуль **Social Import** позволяет автоматически загружать посты из популярных социальных сетей в Google Sheets для дальнейшего анализа с помощью Gemini AI.

**Поддерживаемые платформы:**
- ✅ **Telegram** (Публичные каналы)
- ✅ **VKontakte** (Группы, паблики, личные страницы)
- ✅ **Instagram** (Публичные профили через Bridge)

**Файл:** `deploy/SocialImport.gs`

---

## ⚙️ Настройка и Использование

### 1. Подготовка листа
Для работы импорта необходим лист с именем **"Посты"** (или настройки берутся из специального конфигурационного листа, если он используется в вашей версии).

Скрипт ожидает параметры в ячейках листа **"Посты"** (или "Параметры"):
- **C1**: Ссылка на источник или ID (например, `https://t.me/durov` или `vk.com/apiclub`)
- **E1**: Количество постов для загрузки (по умолчанию 20)

### 2. Запуск
Запуск производится через меню:
`🤖 Table AI` → `📱 Импорт соцсетей` (или аналогичный пункт)

## 🔧 Технические детали по платформам

### ✈️ Telegram
- **Метод:** Прямой парсинг Web-preview версии (`t.me/s/channelname`).
- **Пагинация:** Поддерживается. Скрипт автоматически переходит по ссылкам "Load more" (`?before=ID`) для загрузки старых постов.
- **Ограничения:**
    - Только публичные каналы.
    - Чаты и приватные группы не поддерживаются.
    - Текст может быть урезан, если он очень длинный (ограничение Web-preview).

### 🟦 VKontakte (VK)
- **Метод:** Использование внешнего PHP-парсера (VK Parser).
- **Конфигурация:**
    - Требуется глобальная переменная `VK_PARSER_URL` (обычно задается в `ScriptProperties` или в коде).
    - Пример: `https://your-server.com/vk-parser.php`
- **Логика:**
    1. Скрипт определяет `owner_id` или `domain` из ссылки.
    2. Отправляет запрос к `VK_PARSER_URL`.
    3. Парсер возвращает JSON с постами.
- **Поддержка:** Ссылки вида `vk.com/club123`, `vk.com/public123`, `vk.com/id123`, `vk.com/username`.

### 📸 Instagram
- **Метод:** Bridge через сторонний сервис (Picuki).
- **Логика:**
    - Используется `UrlFetchApp` для получения HTML профиля через зеркало.
    - Парсятся блоки с фото и описаниями.
- **Ограничения:**
    - Зависит от доступности bridge-сервиса.
    - Может не работать, если Instagram или Bridge изменят верстку.
    - Только публичные профили.

## 🧩 Структура данных

После импорта данные записываются в лист **"Посты"** начиная с 3-й строки:

| Колонка | Описание |
|---------|----------|
| **A** | Дата поста |
| **B** | Ссылка на пост |
| **C** | Текст поста |
| **D** | Порядковый номер |
| **E** | (Формула) Стоп-слова |
| **F** | (Формула) Отфильтрованный текст |
| **G** | (Формула) Нумерация фильтра |
| **H** | (Формула) Позитивные слова |
| **I** | (Формула) Текст с позитивными словами |
| **J** | (Формула) Нумерация позитива |

*Примечание: Структура колонок может незначительно отличаться в зависимости от версии `SocialImport.gs`.*

## 🛠️ Troubleshooting (Устранение неполадок)

| Проблема | Возможная причина | Решение |
|----------|-------------------|---------|
| **Telegram: Загружается только 20 постов** | Старая версия скрипта без пагинации | Обновитесь до v3.5.3+ (см. CHANGELOG). |
| **VK: Ошибка "VK_PARSER_URL not defined"** | Не настроен URL парсера | Проверьте `ScriptProperties` или константы в `Main.gs`. |
| **Instagram: Ошибка 404 или пустой список** | Профиль закрыт или Bridge недоступен | Проверьте доступность профиля в браузере. Попробуйте позже. |
| **Ошибка "Лист не найден"** | Удален лист "Посты" | Создайте лист с именем "Посты" заново. |
