# Unpacking Viewer Module

## Обзор

Модуль **Unpacking Viewer** предоставляет удобный интерфейс для просмотра и экспорта данных из листа "Распаковка" в Google Sheets.

## Файлы

### Backend
- **`UnpackingViewer.gs`** - Основные функции модуля
  - `openUnpackingViewer()` - Открытие модального окна
  - `getUnpackingData()` - Чтение данных из листа "Распаковка"
  - `exportUnpackingToDoc()` - Экспорт данных в Google Docs

### Frontend
- **`UnpackingViewerUI.html`** - HTML интерфейс с полным функционалом
  - Интерактивные карточки с анимацией
  - Массовое управление (развернуть/свернуть всё)
  - Экспорт в документ и скачивание .docx
  - Адаптивный дизайн с тёмной темой

### Интеграция
- **`Main.gs`** - Обновлён для добавления пункта меню "📦 Просмотр Распаковки"

## Функциональность

### Основные возможности:
1. **Просмотр данных** - 8 полей из листа "Распаковка" (A2:H2 заголовки, A3:H3 данные)
2. **Интерактивные карточки** - Разворачивание/сворачивание с плавной анимацией
3. **Массовое управление** - Кнопки "Развернуть всё" и "Свернуть всё" с каскадной анимацией
4. **Экспорт в Google Docs** - Создание форматированного документа
5. **Скачивание .docx** - Прямое скачивание файла на компьютер
6. **Обновление данных** - Перезагрузка без закрытия окна

### Технические особенности:
- Современный CSS с переменными и тёмной темой
- Плавные анимации (300ms для карточек, 50ms каскад)
- Полная обработка ошибок
- Логирование через `addLog()`
- Адаптивный дизайн
- Экранирование HTML для безопасности

## Использование

1. Откройте Google Sheets
2. Выберите меню **🤖 Table AI → 📦 Просмотр Распаковки**
3. В модальном окне просмотрите данные
4. Используйте кнопки управления для навигации
5. Экспортируйте данные при необходимости

## Структура данных

### Входные данные (лист "Распаковка"):
- **Строка 2 (A2:H2)** - Заголовки полей
- **Строка 3 (A3:H3)** - Значения полей

### Выходные данные (JSON):
```javascript
{
  success: true,
  data: [
    { header: "Заголовок 1", value: "Значение 1" },
    // ... ещё 7 полей
  ],
  error: null
}
```

## Требования

- Лист "Распаковка" должен существовать в таблице
- Данные в диапазонах A2:H2 и A3:H3
- Разрешения на создание Google Docs документов
- Разрешения на доступ к Google Drive

## Логирование

Все действия логируются через `addLog()`:
- `INFO` - основные операции
- `DEBUG` - детальная информация
- `ERROR` - ошибки и исключения
