# CHANGELOG - Table AI

## 🚀 [3.8.0] — 2026-04-15 (SAAS FULL CYCLE)

### ✨ Добавлено (SaaS Solution)
- **Real Social Scrapers:** Реальный импорт из Telegram (t.me/s/), Instagram (via Picuki bridge) и VK (m.vk.com). Больше никаких моков!
- **Prompt Chains (Backend):** Поддержка последовательного анализа данных, где результат предыдущего шага становится входными данными для следующего.
- **Quota & Balance System:** 
    - Проверка баланса пользователя перед каждым вызовом AI.
    - Автоматическое списание баллов (1 балл = 1 запрос в цепочке).
    - Учет ролей (Админы имеют безлимитный доступ).
- **Multi-Provider Architecture:** Подготовлена структура для подключения OpenAI и Anthropic (помимо Gemini).
- **Modern SaaS Dashboard:** 
    - Полностью переработанный UI на React 19.
    - Разделение на сбор данных (Collector), выбор промптов и ленту результатов.
    - Функции копирования в буфер и печати отчетов.
- **D1 Schema Update:** Добавлены поля `balance` и `metadata` для расширенного управления пользователями и контентом.

### 🔧 Исправлено
- **Social Import Logic:** Улучшен парсинг HTML для Telegram и Instagram, добавлена обработка ошибок сети.
- **AI Context Handling:** Исправлена склейка текстов при пакетном анализе (добавлены разделители и заголовки).
