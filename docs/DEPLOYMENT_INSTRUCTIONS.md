## ⚡ Быстрый старт:

1. Откройте Google Sheets → Расширения → Apps Script
2. Скопируйте все файлы из папки **deploy/**
3. Получите Gemini API ключ: https://aistudio.google.com/app/apikey
4. Настройте ключ через меню: 🤖 Table AI → ⚙️ Настройки

**Время развертывания:** ~10-15 минут
