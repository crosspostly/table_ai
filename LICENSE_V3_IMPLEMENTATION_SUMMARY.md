## 🔄 FLOW РАБОТЫ СИСТЕМЫ

### **Сценарий: Сохранение настроек**

```
1. UI → saveSettingsData(data)
   ↓
2. КЛИЕНТ: validateLicense(email, token)
   - Получает scriptId = ScriptApp.getScriptId()
   - Получает spreadsheetId = SpreadsheetApp.getId()
   - Формирует payload: {action: 'validate', email, token, scriptId, spreadsheetId}
   - Отправляет HTTP POST на SERVER_URL
   ↓
3. СЕРВЕР: doPost() → case 'validate'
   - Вызывает checkLicense_() из license.gs
   ↓
4. МОДУЛЬ: checkLicense_()
   - Проверяет лицензию в "Tokens"
   - Проверяет привязки в "Bindings"
   - Возвращает результат (БЕЗ добавления привязки)
   ↓
5. СЕРВЕР: Возвращает JSON ответ
   ↓
6. КЛИЕНТ: Анализирует результат
   - Если ok: true → сохраняет в ScriptProperties
   - Если ok: false → возвращает ошибку
```

### **Сценарий: Обычная работа**

```
1. UI → serverGM() / serverGMImage() / др.
   ↓
2. КЛИЕНТ: serverStatus()
   - Формирует payload: {action: 'status', email, token, scriptId, spreadsheetId}
   - Отправляет HTTP POST на SERVER_URL
   ↓
3. СЕРВЕР: doPost() → case 'status'
   - Вызывает checkLicense_() из license.gs
   ↓
4. МОДУЛЬ: checkLicense_()
   - Проверяет лицензию в "Tokens"
   - Проверяет привязки в "Bindings"
   - ЕСЛИ НУЖНО: добавляет новую привязку
   - Обновляет copies_count
   - Сортирует листы
   ↓
5. СЕРВЕР: Возвращает JSON ответ
   ↓
6. КЛИЕНТ: Разрешает или запрещает выполнение
```
