## 🚀 Быстрый старт

### 1. Прочитайте инструкцию
📖 [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) - **НАЧНИТЕ ЗДЕСЬ!**

### 2. Скопируйте файлы в Google Apps Script

```
1. Откройте Google Sheets
2. Расширения → Apps Script
3. Создайте файлы (см. DEPLOYMENT_GUIDE.md)
4. Скопируйте содержимое из этой папки
5. Сохраните (Ctrl+S)
6. Обновите страницу Google Sheets (F5)
```

### 3. Настройте API ключ

```
Меню → 🤖 Table AI → 🔑 Установить API ключ Gemini
```

## ✅ Что работает

- ✨ **Table AI базовый функционал** - все старые функции сохранены
- 🎯 **AI Конструктор (Template System v2.0)** - новая система шаблонов
- 💾 **PropertiesService storage** - быстрое хранение шаблонов

- 👥 **Multi-user support** - каждый пользователь со своими шаблонами
- 🔒 **LockService protection** - защита от race conditions
- 📝 **Логирование** - полное логирование всех операций

## ⚠️ Важные замечания

1. **Backup перед развертыванием!**
   - Сделайте копию существующих скриптов
   - Сохраните текущие данные

2. **Первый запуск требует разрешений**
   - Google попросит разрешения на доступ
   - Это нормально - разрешите доступ

3. **DEV_MODE включен по умолчанию**
   - Меню "🧰 DEV" будет видно
   - Для продакшна: установите `DEV_MODE = false` в Main.gs

4. **Совместимость**
   - Все старые функции Table AI сохранены
   - Обратная совместимость гарантирована
   - Миграция из ConfigData опциональна
