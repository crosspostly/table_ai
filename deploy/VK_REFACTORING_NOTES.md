**Что сделано:**
- Все функции работы с VK импортом вынесены из Main.gs в отдельный файл VK.gs
- Исправлена критическая ошибка "arr is not defined" - переменная теперь объявлена вне try-catch блока
- Вызовы VK скрипта (importVkPosts, createStopWordsFormulas) глобально доступны для меню и UI

**Исправленные ошибки:**
