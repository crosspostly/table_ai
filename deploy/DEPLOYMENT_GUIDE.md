## 🚀 ПОШАГОВАЯ ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ

### ШАГ 1: Подготовка Google Sheets документа

1. Откройте ваш Google Sheets документ
2. Перейдите в **Расширения → Apps Script**
3. Вы увидите редактор скриптов

### ШАГ 2: Очистка существующих файлов (опционально)

Если у вас уже есть скрипты:

1. **ВАЖНО:** Сделайте backup существующих скриптов!
2. Можете оставить существующие файлы и просто добавить новые

### ШАГ 3: Загрузка файлов .gs (Google Apps Script)

Создайте следующие файлы в редакторе скриптов (кнопка **+** → **Скрипт**):

#### 3.1. Файл: `Main.gs`
```
1. Нажмите + → Скрипт
2. Назовите: Main
3. Скопируйте содержимое из deploy/Main.gs
4. Вставьте и сохраните (Ctrl+S)
```

#### 3.2. Файл: `server.gs`
```
1. Нажмите + → Скрипт
2. Назовите: server
3. Скопируйте содержимое из deploy/server.gs
4. Вставьте и сохраните (Ctrl+S)
```

#### 3.3. Файл: `TemplateService.gs`
```
1. Нажмите + → Скрипт
2. Назовите: TemplateService
3. Скопируйте содержимое из deploy/TemplateService.gs
4. Вставьте и сохраните (Ctrl+S)
```

#### 3.4. Файл: `CollectConfigUI.gs`
```
1. Нажмите + → Скрипт
2. Назовите: CollectConfigUI
3. Скопируйте содержимое из deploy/CollectConfigUI.gs
4. Вставьте и сохраните (Ctrl+S)
```

#### 3.5. Файл: `MIGRATION.gs`
```
1. Нажмите + → Скрипт
2. Назовите: MIGRATION
3. Скопируйте содержимое из deploy/MIGRATION.gs
4. Вставьте и сохраните (Ctrl+S)
```

### ШАГ 4: Загрузка HTML файлов

В редакторе Apps Script слева вы должны видеть:

```
Файлы
  📄 Main.gs
  📄 server.gs
  📄 TemplateService.gs
  📄 CollectConfigUI.gs

  📄 CollectConfigUI_v2.html
```

### ШАГ 6: Сохранение и развертывание

1. Нажмите **💾 Сохранить проект** (Ctrl+S)
2. Дайте имя проекту: `Table AI v2.0`
3. Закройте редактор скриптов
4. **Обновите страницу Google Sheets** (F5)

### ШАГ 7: Первый запуск

1. В Google Sheets появится новое меню: **🤖 Table AI**
2. При первом клике на меню:
   - Google попросит разрешения
   - Нажмите **"Продолжить"**
   - Выберите ваш аккаунт
   - Нажмите **"Разрешить"**

## 🐛 УСТРАНЕНИЕ НЕПОЛАДОК

### Проблема 1: Меню не появляется

**Решение:**
1. Обновите страницу (F5)
2. Закройте и откройте документ заново
3. Проверьте, что файл `Main.gs` загружен корректно
4. Проверьте функцию `onOpen()` в Main.gs

### Проблема 2: "CollectConfigUI_v2 not found"

**Причина:** HTML файл не загружен или назван неправильно

**Решение:**
1. Проверьте имя файла: должно быть **точно** `CollectConfigUI_v2`
2. Убедитесь, что это HTML файл (📄 с оранжевым значком)
3. Пересоздайте файл: + → HTML → CollectConfigUI_v2

### Проблема 3: "function not defined"

**Причина:** Не все .gs файлы загружены

**Решение:**
1. Проверьте все файлы из ШАГ 3
2. Убедитесь, что все файлы сохранены (Ctrl+S)
3. Обновите страницу Google Sheets

### Проблема 4: Ошибка "API key not set"

**Решение:**
```
Меню → 🔑 Установить API ключ Gemini
```
Введите ваш Gemini API ключ.

### Проблема 5: Медленная работа

**Причина:** Первый запуск или холодный старт

**Решение:**
1. Подождите 5-10 секунд
2. При повторных запросах будет быстрее (кэш)
3. PropertiesService может тормозить при первом доступе

### Проблема 6: Шаблоны не сохраняются

**Причина:** Ошибка в TemplateService.gs

**Решение:**
1. Проверьте логи: **🧰 DEV → 📝 Показать логи**
2. Убедитесь, что `TemplateService.gs` загружен полностью
3. Проверьте квоты PropertiesService (500KB лимит)
