## 🔄 Логика работы новой системы:

### Двойная идентификация:
- **Script ID**: Используется для привязки лицензии (уникальный, не меняется при копировании)
- **Spreadsheet ID**: Используется для работы с данными и получения названия таблицы

### Сценарии работы:

1. **Первая привязка:**
   - script_ids пустое → привязываем новый скрипт
   - Записываем в G: scriptId
   - Записываем в E: spreadsheetId + название + дата
   - Уменьшаем F: copies_count

2. **Повторное открытие:**
   - scriptId уже есть в G → разрешаем доступ
   - Не списываем копию

3. **Множественная привязка:**
   - scriptId нет в G, но copies_count > 0
   - Добавляем новый scriptId в G
   - Добавляем новый spreadsheetId в E
   - Уменьшаем copies_count

4. **Валидация при сохранении:**
   - Проверяем лицензию на сервере ПЕРЕД сохранением
   - При ошибке → данные НЕ сохраняются
   - При успехе → сохраняем и показываем логи
